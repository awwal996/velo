# Assets Folder

This folder contains images and other static assets for the Velontri chatbot.

## 📸 Add Your Logo Here

### Step 1: Save the Velontri Logo
1. Save your Velontri phoenix logo image as: **`velontri-logo.png`**
2. Place it in this folder: `frontend/assets/velontri-logo.png`

### Step 2: Image Requirements
- **Filename:** Must be exactly `velontri-logo.png`
- **Format:** PNG (preferred) or JPG
- **Size:** Recommended 400x400px or larger (square)
- **Background:** Can be transparent or black (your phoenix logo)

### Step 3: See It Live
After adding the image:
1. Refresh your browser: `Ctrl + Shift + R`
2. The logo will appear in:
   - Header (top left)
   - Chat bubbles (next to Velo responses)

## 💡 Tips

**If logo doesn't appear:**
1. Check filename is exactly: `velontri-logo.png` (case-sensitive)
2. Check file is in correct folder: `frontend/assets/`
3. Hard refresh browser: `Ctrl + Shift + R` or `Ctrl + F5`
4. Check browser console for errors (F12)

**For best quality:**
- Use PNG format (supports transparency)
- Square aspect ratio (1:1)
- At least 400x400 pixels
- Optimize file size (< 200KB)

---

## 🔄 Alternative: Use JPG

If you have a JPG file instead:
1. Rename it to: `velontri-logo.png` (yes, keep .png extension)
2. Or update the code in `index.html` to use `.jpg`

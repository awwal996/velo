✅ How to Test:

  1. Make sure the chatbot is running on http://localhost:3000
  2. Open the browser's Developer Console (F12 or Ctrl+Shift+I)
  3. Dark Mode Test: Click the "Toggle Dark Mode" button above
  4. Watch the console logs - you should see [Velo Dark Mode] messages
  5. The chatbot background should change from white to dark automatically
  6. Navigation Test: Search for something in the chatbot (e.g., "cars")
  7. Click on a listing card - it should show a confirmation dialog
  8. In production, this will navigate the parent page (no new tab)
  9. Toggle multiple times to verify everything syncs correctly
